Como consta no edital

📋 Texto oficial do edital: Mineração de dados (Balanced Scorecard).

O que é

Mineração de dados (data mining) é o processo de explorar grandes volumes de dados em busca de padrões, relações e tendências que não são óbvios à primeira vista — usando técnicas como classificação (prever a qual categoria um caso pertence, ex.: "esse cliente vai cancelar o serviço?"), agrupamento/clusterização (juntar casos parecidos sem categorias pré-definidas, ex.: perfis de clientes) e associação (encontrar itens que costumam aparecer juntos, ex.: "quem compra X também compra Y"). O Balanced Scorecard (BSC), citado junto no edital, é uma ferramenta de gestão estratégica que usa indicadores para acompanhar se a empresa está de fato executando sua estratégia — e não uma técnica de mineração de dados propriamente dita, mas um dos principais consumidores dos indicadores gerados por BI e mineração de dados dentro da empresa.

Como funciona

O BSC organiza os objetivos e indicadores da empresa em quatro perspectivas que se conectam numa relação de causa e efeito: Financeira (o resultado final que os acionistas esperam), Clientes (o que precisa ser entregue a eles para gerar esse resultado), Processos internos (o que a empresa precisa fazer bem para satisfazer os clientes) e Aprendizado e crescimento (pessoas, sistemas e cultura — a base que sustenta tudo o resto). A lógica é: investir em Aprendizado e crescimento melhora os Processos internos, que melhoram a entrega aos Clientes, que gera o resultado Financeiro esperado.

Um projeto de mineração de dados costuma seguir etapas parecidas com o ciclo CRISP-DM: entender o problema de negócio, entender e preparar os dados, construir o modelo (ex.: uma árvore de decisão para classificação), avaliar se o modelo é bom o suficiente e, por fim, implantá-lo no processo real da empresa.

Exemplos resolvidos

  1. Um supermercado descobre, analisando o histórico de compras, que quem compra fraldas também costuma comprar cerveja no mesmo carrinho. Que técnica de mineração de dados foi usada?
    Resolução: análise de associação (o clássico exemplo de "market basket analysis" / análise de cesta de compras) — busca padrões do tipo "quem compra X também compra Y".
  2. Uma operadora de telecom quer prever, para cada cliente atual, se ele vai cancelar o plano nos próximos 3 meses. Que técnica de mineração de dados se aplica melhor?
    Resolução: classificação — o objetivo é prever a qual categoria (vai cancelar / não vai cancelar) cada cliente pertence, com base no histórico de clientes que já cancelaram ou não antes.
  3. No BSC, um indicador de "tempo médio de treinamento por funcionário" pertence a qual das quatro perspectivas?
    Resolução: Aprendizado e crescimento — é a perspectiva que trata de pessoas, capacitação, sistemas e cultura organizacional, a base que sustenta as demais perspectivas.
