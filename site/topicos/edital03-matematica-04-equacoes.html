Como consta no edital

📋 Texto oficial do edital: Equações: equações do 1º grau, do 2º grau, exponenciais, logarítmicas e sistemas de equações lineares.

O que é

Equações são igualdades com uma incógnita a ser descoberta. As mais cobradas: 1º grau (ax + b = 0); 2º grau (ax² + bx + c = 0); exponenciais (a incógnita aparece no expoente); logarítmicas (a incógnita aparece dentro de um logaritmo); e sistemas de equações lineares (duas ou mais equações do 1º grau que devem ser satisfeitas ao mesmo tempo).

Como funciona

1º grau: isola-se x → x = −b/a.

2º grau: usa-se a fórmula de Bhaskara: x = (−b ± √Δ) / 2a, onde Δ = b² − 4ac (o "discriminante"). Se Δ > 0, há duas raízes reais distintas; se Δ = 0, uma raiz dupla; se Δ < 0, não há raiz real.

Exponenciais: quando possível, reduz-se os dois lados à mesma base e iguala-se os expoentes (se aˣ = aʸ, então x = y).

Logarítmicas: usa-se as propriedades dos logaritmos para isolar a incógnita, sempre verificando as condições de existência (o "logaritmando" precisa ser positivo).

Sistemas lineares: resolve-se por substituição (isola uma variável numa equação e substitui na outra) ou por adição (soma ou subtrai as equações, multiplicadas por constantes convenientes, para eliminar uma variável).

Exemplos resolvidos

  1. Resolva 3x − 7 = 11.
    Resolução: 3x = 18 → x = 6.
  2. Resolva x² − 5x + 6 = 0.
    Resolução: Δ = (−5)² − 4·1·6 = 25 − 24 = 1. x = (5 ± 1)/2 → x = 3 ou x = 2.
  3. Resolva 2ˣ = 32.
    Resolução: 32 = 2⁵, então 2ˣ = 2⁵ → x = 5.
  4. Resolva o sistema {x + y = 10; x − y = 2}.
    Resolução (por adição): somando as duas equações, 2x = 12 → x = 6; substituindo, 6 + y = 10 → y = 4.
